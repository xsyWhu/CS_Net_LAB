# FTP 客户端实践推进计划

## 1. 开发环境

- 开发系统：WSL2 Linux + VSCode
- 目标运行系统：Windows
- 编程语言：Java
- GUI：Swing
- 协议实现：`java.net.Socket`
- 构建方式：`javac` 脚本构建，不依赖 Maven/Gradle

## 2. FTP 协议功能

第一阶段先实现控制连接：

- `Socket(host, 21)` 建立 TCP 控制连接
- 读取服务器欢迎响应 `220`
- `USER` / `PASS` 登录
- `PWD` 获取当前目录
- `CWD` 切换目录
- `QUIT` 退出

第二阶段实现目录和文件传输：

- `TYPE I` 使用二进制传输
- `PASV` 进入被动模式
- `LIST` 获取远程目录
- `RETR` 下载文件
- `STOR` 上传文件

第三阶段实现断点续传：

- 下载续传：本地已有部分文件时，发送 `REST 本地文件大小`，再发送 `RETR`
- 上传续传：远程已有部分文件时，发送 `REST 远程文件大小`，再发送 `STOR` 或 `APPE`
- 传输进度条和日志记录

## 3. GUI 功能

- 服务器地址、端口、用户名、密码输入
- 连接、断开按钮
- 远程目录列表
- 本地文件选择
- 上传、下载按钮
- 续传上传、续传下载按钮
- 传输进度条
- 操作日志输出

## 4. 测试方案

开发阶段建议在 WSL2 中安装或启动一个本地 FTP 服务进行测试，最终在 Windows 上运行 jar 包截图。

当前项目已提供内置测试服务器：

```bash
python3 tools/dev_ftp_server.py --host 127.0.0.1 --port 2121 --root ftp-root
```

连接参数：

- 主机：`127.0.0.1`
- 端口：`2121`
- 用户名：任意
- 密码：任意

可测试场景：

- 匿名登录或账号密码登录
- 查看当前目录
- 切换远程目录
- 下载小文件
- 上传小文件
- 中断后继续下载
- 中断后继续上传

## 5. 实验报告素材

报告中可以说明：

- 使用 Socket 建立 FTP 控制连接和数据连接
- FTP 控制连接负责发送命令和读取响应
- 文件传输使用被动模式 `PASV` 创建数据连接
- 断点续传使用 `REST` 命令指定偏移量
- GUI 使用 Swing 实现
